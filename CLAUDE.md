# Artdle Web — CLAUDE.md

## What this project is

**Artdle** is an idle painting game. The player grows an inspiration tree, paints canvases for gold, ascends when inspiration hits a threshold (converts to permanent fame), and spends fame in a skill tree. The Workshop produces equippable items that boost the canvas. This repo is the **web port** of a Godot prototype; v1 ships a stripped minimum playable loop, and waves v1.1+ progressively bring richness online from the source design specs.

**Tech stack:** React 19 + TypeScript strict + Vite + Tailwind 4 (CSS-first config) + Zustand 5 (one store with slices, persist middleware) + IndexedDB via `idb-keyval` + `break_eternity.js` (big numbers) + Motion + Vitest.

**Long-term target:** ~3 years of player time to fully unlock the game once all features ship. v1 itself plays in 1-3 hours.

## How to work in this repo

- **Plan-driven.** Every non-trivial change starts from a written plan in `docs/superpowers/plans/`. Plans decompose into bite-sized tasks (test → fail → impl → pass → commit). Don't implement off-plan.
- **TDD.** Tests precede implementation. Every formula in `src/core/balance.ts` has a Vitest test in `tests/core/balance.test.ts`.
- **Frequent commits.** One commit per task step is fine. Commit messages are conventional: `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, `core:`, `store:`, `ui:`, etc.
- **Subagent-driven dev workflow.** When executing plans, prefer dispatching one subagent per task and reviewing between tasks (see `docs/agent_docs/workflow.md`).
- **English only.** No French in code, comments, UI strings, or docs (the source specs are mixed French/English; that's reference material, not a translation target).

## Key conventions and pitfalls

- **`@/` is the alias for `src/`.** Use it in imports.
- **Big numbers everywhere monetary or inspiration-scale.** `break_eternity.js` via the `Big` type from `@/core/bigNumber`. Don't use raw JS numbers for fame, palier, late-game inspi.
- **Selectors, not whole-store subscriptions.** `useGameStore((s) => s.gold)` — never `useGameStore()` from a component.
- **InfoPanel is a fixed strip, not a tooltip.** Hover info pushes through the `hoverInfoSlice`. Don't reach for Radix Tooltip / Popover.
- **Offline progress is a 24h-capped catch-up** (`src/systems/catchup.ts`). Tab hidden = ticking pauses (no live ticks while backgrounded); on return, elapsed time is replayed via the pure tick functions against a cloned draft, then committed once. The replay step size scales with the elapsed window (`chooseDelta`).
- **Save persists via `idb-keyval`.** First render gates on rehydration completion (see `src/main.tsx` Bootstrap).
- **`playerId` is a UUID v4 inside the save object.** Generated by the meta slice initializer; preserved across ascends and migrations.

## Deployment

- **Production URL:** https://artdle-web.vercel.app
- **Deploy command:** `npx vercel --prod` from the repo root. This builds and pushes to production directly. Do not use localtunnel.
- **Vercel is not wired to auto-deploy from git push** — always run `npx vercel --prod` after pushing to trigger a production build.
- **Verify deployment:** after `npx vercel --prod` completes, fetch `/assets/index-<hash>.js` from the production URL and grep for a known string (e.g. a route name) to confirm the new bundle is live.

## Out of scope (permanently)

Mobile-first design, multiplayer, French language. The game ships in English on desktop browsers only.

## Out of scope (still deferred)

Expositions, multi-art-form architecture, PWA, backend, accounts. See `docs/PORT_PLAN.md` §13 for the full deferred list and §2.1 for the wave roadmap.

**Already shipped (no longer deferred):** Painter's Office, Painting School, audio (canvas-sold SFX + music), achievements, and offline progress (24h-capped catch-up via `src/systems/catchup.ts`). The original "no audio / no achievements / no offline progress in v1" framing is historical — those waves landed in the 2026-05-30/31 cycles.

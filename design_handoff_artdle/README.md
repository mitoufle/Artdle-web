# Handoff · Artdle UI

A web-based idle/clicker about an artist who paints, sells art, grows a metaphysical tree, and ascends through mystical thresholds to gain permanent fame. This bundle hands off the visual + structural design of the four main views.

---

## About the design files

The HTML files in this bundle are **design references** — prototypes built in plain HTML/CSS/SVG to communicate intended look and feel. They are **not production code to copy**. Your job is to recreate these designs in the target project's existing stack (React, Vue, Svelte, etc.), using its established component patterns, routing, and state management.

If the project has no frontend yet, choose a stack appropriate to the scope (idle game = lots of state + ticking timers + persistent storage; React + Zustand/Jotai or Svelte + stores both work well).

## Fidelity

**High-fidelity.** Final colors, typography, spacing, and structure. Recreate pixel-perfectly within the chosen stack, but use your own component primitives — don't copy CSS class names verbatim.

## Aesthetic direction

- **Dark mystic palette.** Deep indigo/violet (`#0a0814` → `#3a2e5a`) backgrounds, parchment-ivory text (`#f4efe6`), three luminous currency accents.
- **Three currencies, three colors:**
  - **Gold** `#e6b667` — main loop currency. Earned by selling paintings.
  - **Inspiration** `#9b6cd6` — passive resource, generated by the Tree.
  - **Fame** `#ffd86a` — prestige currency. Earned by ascending; spent in the Constellation.
- **Glowy.** Currencies, portals, and active nodes all use soft outer glows (see `--gold-glow`, `--inspi-glow`, `--fame-glow`). Sparingly applied — only "important" elements glow.
- **Pixel-art accents inside an otherwise serif/refined frame.** The Tree, the painting being created, item slots, and currency icons are pixelated. Window chrome, headings, and buttons are clean and ornate (Cinzel serif).
- **Typography**:
  - Cinzel (uppercase, wide letter-spacing) → all titles, nav items, prestige labels, button text.
  - JetBrains Mono → numbers, meta info, labels, tooltips.
  - Inter → body copy.
  - Press Start 2P / VT323 → reserved for inside pixel-art elements only.
- **No emoji** in production. The mock uses a couple as placeholders (⚒ 👤 📜 ⚗ 🖼) — replace with actual icons in your icon library.

## Information architecture

A single-page app with a persistent top nav, persistent bottom currency bar, and four routes:

1. **The Tree** (Home) — `/tree`
2. **Painting View** — `/painting`
3. **Ascension** — `/ascension`
4. **Constellation** (Skill Tree) — `/constellation`

### Top bar (persistent)

- Brand wordmark "ARTDLE" left (Cinzel 700, 22px, the leading "A" tinted fame-gold).
- Nav (Cinzel uppercase, 13px, 0.18em letter-spacing). Active item: tinted fame-gold + ✦ flourishes left/right + thin gold border.
- Far right: tiny mono microcopy showing autosave status + settings link.

### Bottom bar (persistent)

A grid: `[currencies] [info panel] [meta chip]`.

- **Currencies** — three pill chips: Gold / Inspiration / Fame. Each chip holds an icon, a number, and a per-second rate (where applicable). Currencies that don't apply to the current view **dim to 28% opacity + saturate(0.4)**, they don't disappear. Fame has no per-second rate.
- **Info panel** — context-sensitive: shows the title + tooltip body for whatever the user just hovered (an upgrade, a node, a slot…). Title in Cinzel, body in mono. Updated via a global hover bus.
- **Meta chip** — version / build label.

### Currency icons (pixel-art, drawn in CSS)

```css
.icon-gold  { /* circle with radial highlight + dark inset */ }
.icon-inspi { /* 8-point pixel sparkle, clip-path star */ }
.icon-fame  { /* 5-point pixel star, clip-path */ }
```

See `Artdle Hi-Fi Mockup.html` lines for `.icon-gold/.icon-inspi/.icon-fame` for exact CSS.

The 5 upgrades are **Roots, Trunk, Foliage, Branch, Bloom** — all spend gold to add to inspi/s.

**Stage tree (data)** — Seed → Sapling → Young Tree → Grand Tree. The visual canopy mass and trunk girth grow with stage; for now we only show the Sapling state.

## Screen 2 · Painting View

**Purpose** — active loop. A canvas auto-paints, completes, sells for gold. Around the canvas are upgrades that affect the canvas itself, plus rooms (Workshop / Office / School / Lab) that contain deeper systems.

**Layout** — CSS grid:
```
grid-template-columns: 1fr 340px 64px;
grid-template-rows: 1fr auto;
grid-template-areas:
  "stage  room  rail"
  "canvas-up room rail";
gap: 14px;
```

**Stage (top-left)** — `.canvas-stage`. A vignetted dark room. In the middle: a gilded picture frame (border-image gradient gold→bronze, 4px) containing a small pixel landscape SVG. A `.canvas-fill` overlay (animated `height` between 30%↔65% via JS RAF loop) gives the impression of paint filling in from the bottom. Title row top-center: `— Tier 2 · Masterpiece —`. Below the title: a thin gold progress bar at 62%. Bottom row over the frame: `Painting · 3.7s / 6.0s` (left), `+184g on next sale` (gold-glowing, center), `▲ Upgrade Tier · 12K g` (right). A trapezoidal pixel "easel" peeks up from the bottom edge.

**Canvas upgrades strip (bottom-left, ALWAYS VISIBLE, never hidden behind a tab)** — `.canvas-upgrades`. A 5-column horizontal strip:
- Col 1 — **Tier card** (gold border, gold glow): label `Canvas Tier`, big serif `II → III`, full-width `Upgrade · 12K g` button.
- Cols 2–5 — small upgrade cards. Each: row of [icon-tile] [name uppercase serif] [Lv N mono] / effect line in mono / cost pill bottom-left.
  - **Strokes** ⏱ — Lv 4 · `−0.4s / paint` · 640g
  - **Pigments** $ — Lv 6 · `+18% sale` · 820g
  - **Auto-Sell** ✦ (purple variant) — Lv 2 · `on completion` · 1.2K g
  - **2nd Easel** ◎ (purple, locked/dimmed) — Lv 0 · `paint in parallel` · 5K g

The rationale: the canvas is the heart of the gameplay loop and its upgrades must always be one click away. They are **not** a "Canvas room" peer to Workshop/Office/School/Lab — they are special.

**Room panel (right)** — `.panel.bordered`, 340px wide, full height of paint area. Header: room title + "Craft · Equip" crumb. Active room shown is **Workshop**:
- **Craft station** — `Roll an item · Random affix · 5–15% magnitude` + `Craft · 200g` button.
- **Equipped slots** — 1/2 (Slot II locked), 1×2 grid of square slots. Slot 1 holds a `+12% gold` rare item (blue border).
- **Inventory** — 4/12 mono label, 4×2 grid of slots: rare/magic/epic/legendary (each border + text colored by tier).
- **Recent legendary detail card** — affix card, legendary border + glow, contains the affix text + small ghost `Equip` button.

**Room rail (far right)** — vertical 64px rail. Each tab is a tile with an emoji icon + 9px mono uppercase label. Tabs: **Workshop** (active), **Office**, **School**, **Lab**. Active tab: inspi-purple gradient bg, ink-1 text, inset purple glow.

**Other rooms** (not implemented in mock, define stub UIs):
- **Office** — manage employees who paint for you (Auto-Painters, marketing).
- **School** — research tree for unlocking new techniques + tiers.
- **Lab** — alchemy / experimental modifiers (consumable boosts, randomized buffs).

**Loot rarity colors** (re-stated for slots/items):
- Rare `#6fb1ff` / Magic `#d57bff` / Epic `#ffb867` / Legendary `#ff7a4a`. Legendary items get an inner box-shadow glow.

## State model (suggested)

```ts
type Currency = 'gold' | 'inspi' | 'fame';

type Game = {
  // currencies
  gold: number;            // float, +ratePerSec when painting completes
  inspi: number;           // float, +inspiPerSec each tick
  fame: number;            // integer, only changes on ascend / spend

  // rates (recomputed from upgrades + affixes + skill nodes)
  inspiPerSec: number;
  goldPerSec: number;      // implicit: paintingPrice / paintingTime
  paintingTime: number;    // sec
  paintingPrice: number;   // gold

  // tree
  treeStage: 'seed' | 'sapling' | 'young' | 'grand';
  treeUpgrades: Record<'roots'|'trunk'|'foliage'|'branch'|'bloom', number>;  // levels

  // canvas
  canvasTier: 1|2|3|4|5;
  canvasUpgrades: Record<'strokes'|'pigments'|'autosell'|'secondEasel', number>;
  paintingProgress: number;     // 0..1

  // workshop
  inventory: Item[];
  equipped: (Item|null)[];      // length 2 (slots unlock with progression)

  // ascension
  ascensionThreshold: number;   // dynamic, based on past runs
  fameOnAscendNow: number;      // computed
  pastRuns: { fame: number; inspi: number }[];

  // constellation
  ownedNodes: Set<NodeId>;
  selectedNode: NodeId | null;
};

type Item = {
  id: string;
  tier: 'rare'|'magic'|'epic'|'legendary';
  affix: { kind: string; magnitude: number; label: string };
};
```

Tick the game on a 100ms (or 16ms) interval; only repaint affected currency chips. Persist to localStorage on every tick coalesced to once per ~2s, plus on visibility change.

## Interactions

- **Top nav** click → switch route, dim irrelevant currency chips, swap info-panel default content.
- **Currency chip hover** → info panel shows currency description + sources.
- **Upgrade row click** (anywhere) → buy if affordable, animate gold chip down, animate row pulse. If not affordable, shake the cost pill.
- **Upgrade row hover** → info panel shows "Lv N → Lv N+1, +Δ effect, cost X".
- **Canvas tier upgrade** → modal confirmation (irreversible mid-run? no — it's just gold, no confirm).
- **Room rail tab** click → swap room panel content, no transition or a soft 120ms fade.
- **Slot click** in inventory → equip into first empty equipped slot, or open a swap menu.
- **Slot hover** → info panel shows full affix text + tier.
- **Portal CTA** → confirmation modal (THIS ONE is irreversible) → animate inspiration draining out, fame ticking up, screen fade to white, then route to Tree fresh run.
- **Constellation node click** → select node (info card updates). Click again to acquire if you have fame.
- **Constellation pan/zoom** → pointer drag pans, wheel zooms. Mini-map viewport rect updates live.

## Animations (durations)

- Currency chip dim/restore: 200ms ease.
- Row hover lift: 140ms.
- Button hover lift: 120ms.
- Portal float: 6s ease-in-out infinite.
- Portal shimmer: 4s ease-in-out infinite.
- Crystal pulse: 3s ease-in-out infinite, staggered.
- Inspiration motes opacity pulse: 2.2s–3.7s, staggered.
- Fireflies: cy + opacity over 6–8s.
- Star twinkle (constellation): 2.5s–4s opacity.

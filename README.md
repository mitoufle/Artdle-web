# Artdle (Web)

An idle painting game — web port of the Godot prototype.

## Status

Pre-v1 development. See `docs/PORT_PLAN.md` for the v1 spec and roadmap.

## Quick start

```bash
npm install
npm run dev    # dev server
npm test       # run tests
npm run build  # production build
```

## Documentation

- `docs/PORT_PLAN.md` — v1 spec and wave roadmap
- `docs/specs/` — source design specs (Godot project — reference only)
